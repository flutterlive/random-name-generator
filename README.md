# Free Random Name, Business Name & Username Generator

Free name generator for new businesses, shops, brands and social media in the USA and UK.

## Features
- Business Name generator: 12 industries, keyword + 7 styles, 12 unique names per batch with domain/handle suggestion
- Username generator: Instagram, TikTok, YouTube, Gaming/Twitch, X formats
- Random Person Name generator: separate USA and UK first/last name pools, male/female/any
- Shop & Brand generator: UK Emporium/Trading Co and .co.uk flavours
- Per-name Copy, Copy All, Generate More, Surprise Me, in-session shortlist
- English only, free, no sign-up, runs 100% in the browser

## How to run
Open `index.html` in any modern browser. No build, no server, no install required.
For hosting, deploy this folder as a static site (for example on Vercel).

## Note
Names are suggestions only. Check availability separately (domain, trademark, social handle) before using a name.
